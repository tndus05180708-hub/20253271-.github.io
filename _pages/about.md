## 1. 자기소개 / About Me

- **전공:** 인공지능공학 전공 (학번: 20253271)
- **관심 분야:** Docker 인프라, Git 버전 관리 시스템, 정보보안
- **진로 목표:** 안전하고 견고한 시스템을 구축하는 정보보안전문가, AI 서비스 개발자
- **현재 학습 중인 기술:** Docker Compose를 활용한 다중 컨테이너 오케스트레이션, Git HEAD 이동 및 브랜치 관리 전략

인공지능공학을 전공하며 인프라 구축과 형상 관리에 깊은 흥미를 느끼고 있습니다. 현재는 Docker를 활용한 컨테이너 오케스트레이션과 Git 기반의 버전 관리 시스템을 심화 학습하고 있으며, 향후 시스템의 취약점을 보완하고 안전한 인프라를 설계하는 정보보안전문가로 성장하는 것을 목표로 합니다.
